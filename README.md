# JavaScript Practice Projects

A collection of five small projects built while learning HTML and JavaScript. Each project is stored in its own folder with a `main.html` file and an `index.js` file.

## What I’m Practising

- Variables, arrays, and functions
- Loops and conditional statements
- Creating and updating HTML elements with JavaScript
- Handling button clicks and user input
- Using timers and browser local storage

## How to Run

1. Download this repository or clone it.
2. Open a project folder.
3. Open its `main.html` file in your browser.
4. Interact with the page to try the project.

No installation or build process is required.

## About

These projects document my learning progress as I build confidence with JavaScript and develop small, interactive web applications.
